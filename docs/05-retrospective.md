# 05 复盘

最难的问题是把模型的“建议 19:00”与“用户同意更改硬性 18:00 要求”分开。实现时把建议保存为待确认草稿；只有输入明确匹配建议时段，才更新确认状态。保存工具还会独立检查审核和时段证据，避免模型文字直接触发越权写入。

本次学习收获是：Agent 的可审计性依赖每次工具观察后的下一步动作，以及写入前的代码级约束。日志只保留简短事实依据，不需要模型内部思维过程。重复提交和保存失败也必须是数据层的真实状态，而非最终回答措辞。

下一步优先事项：用真实模型运行至少冲突与规则风险两条路径，审查其 Trace 并调提示词；引入素材版本以避免旧草稿；接入真实排期系统前补全时间归一化、并发约束和人工确认流程。候选人个人学习与修改记录需在其实际参与后补充。
